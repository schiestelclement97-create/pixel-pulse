Comment ça marche

Touche un mineur pour qu'il aille piocher. Touche l'ascenseur pour remonter le minerai, puis le camion pour le vendre.

Engage un chef d'équipe et ce maillon tourne seul pour toujours, même jeu fermé.

Le maillon le plus lent décide de tout. Si les wagonnets débordent, améliore l'ascenseur. Si le dépôt gonfle, améliore la vente.
