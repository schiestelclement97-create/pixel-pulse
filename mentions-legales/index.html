Installer l'appli

Installer l'appli Pixel Pulse

Mets tous les jeux sur ton écran d'accueil : ils s'ouvrent en plein écran, comme une vraie appli. Gratuit, sans compte, très léger.

✅ C'est installé ! Retrouve Pixel Pulse sur ton écran d'accueil.

Ton navigateur peut installer l'appli en un clic.

Ouvrir dans Chrome
  1. Ouvre playpixelpulsing.fr dans Chrome.
  2. Touche le menu ⋮ en haut à droite.
  3. Choisis Ajouter à l'écran d'accueil puis Installer.
  4. L'icône Pixel Pulse apparaît sur ton écran d'accueil. Touche-la pour jouer.

Samsung Internet marche aussi : menu ☰ → Ajouter la page à → Écran d'accueil.

  1. Ouvre playpixelpulsing.fr dans Safari.
  2. Touche le bouton Partager (le carré avec une flèche vers le haut), en bas de l'écran.
  3. Fais défiler et choisis Sur l'écran d'accueil.
  4. Touche Ajouter en haut à droite. C'est prêt !

Sur iPhone, Chrome marche aussi (iOS 16.4 ou plus) : bouton Partager à droite de la barre d'adresse.

  1. Ouvre playpixelpulsing.fr dans Chrome ou Edge.
  2. Clique sur l'icône Installer (un petit écran avec une flèche) à droite de la barre d'adresse.
  3. Sinon : menu ⋮ → Caster, enregistrer et partager → Installer la page en tant qu'application (Edge : … → Applications).
  4. Clique sur Installer : Pixel Pulse s'ouvre dans sa propre fenêtre.

Firefox et Safari sur Mac ne savent pas encore installer les sites : utilise Chrome ou Edge.

Bientôt sur Google PlayL'appli arrive sur le Play Store. En attendant, l'installation depuis Chrome donne la même appli, avec les mêmes jeux.
